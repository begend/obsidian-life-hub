# 今日任务

收录所有 `type: project` / `type: task` 笔记里的行内任务，以及 `10-Projects`、`timeManage`。

## 进行中

```tasks
not done
status.name includes 进行中
filter by function ['project', 'task'].includes(task.file.property('type')) || task.file.path.includes('10-Projects') || task.file.path.includes('timeManage')
path does not include 90-System/Templates
path does not include PeriodicNotes/Templates
path does not include 010-tpl
sort by priority
hide tags
short mode
```

## 今日开始

```tasks
not done
starts on today
filter by function ['project', 'task'].includes(task.file.property('type')) || task.file.path.includes('10-Projects') || task.file.path.includes('timeManage')
path does not include 90-System/Templates
path does not include PeriodicNotes/Templates
path does not include 010-tpl
sort by priority
hide tags
short mode
```

## 今日计划 / 到期

```tasks
not done
(scheduled on today) OR (due on today)
filter by function ['project', 'task'].includes(task.file.property('type')) || task.file.path.includes('10-Projects') || task.file.path.includes('timeManage')
path does not include 90-System/Templates
path does not include PeriodicNotes/Templates
path does not include 010-tpl
sort by due
hide tags
short mode
```
